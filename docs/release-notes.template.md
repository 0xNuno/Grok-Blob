## Blob v1.0.0

Quiet Mac overlay for Grok Bot agents (MIT).

### Install
- Download the .dmg or .zip for your Mac arch (arm64 or x64).
- Open / copy Blob.app to Applications.
- If macOS warns on first open: Right-click then Open.

### First run
- Gateway URL + token (localhost or private mesh). See docs/connecting.md.
- Screen Recording for capture.
- Summon: Command+Shift+Space.

### Notes
- Build may be unsigned unless Apple credentials were used for this tag.
- Token never belongs in issues or release comments.
